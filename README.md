🏦 City Bank Management System (C++)

A simple console-based Bank Management System implemented in C++ using file handling.
This project allows users to create a bank account, deposit money, withdraw money, and check account details.

📌 Features

✔ Create a new bank account
✔ Auto-generated account number
✔ Deposit money
✔ Withdraw money
✔ View account details
✔ Data stored persistently using files (data.txt)

🛠️ Technologies Used

Language: C++

Concepts Used:

Classes & Objects

File Handling (fstream)

Switch-case

Loops

Basic Input/Output
